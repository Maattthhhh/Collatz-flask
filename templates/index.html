      The Collatz conjecture is a famous unsolved problem in mathematics introduced by German mathematician Lothar Collatz in 1937.

      The Rules:

        If \(n\) is even, divide it by 2 (\(n / 2\)).
        If \(n\) is odd, multiply it by 3 and add 1 (\(3n + 1\)).

      Repeat this process continuously with each new result. The Collatz conjecture states that no matter which positive integer you start with, the sequence will always eventually reach 1.
